# Better Space Platform: Updated

Retains the original space-platform building changes on Factorio 2.1.

Requires Factorio 2.1.24 or later. Enable the dependencies listed in the mod manager. This fork keeps the original mod’s content rather than introducing a new balance model.

Existing saves using better-space-platform can migrate to this mod identity. Keep a backup when changing a mod set, and disable the original when selecting this fork.

Original mod: [ better-space-platform ](https://mods.factorio.com/mod/better-space-platform). Original author credits and applicable license notices are retained in the source package.
